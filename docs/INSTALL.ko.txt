콜 오브 듀티: 고스트 한글패치 — 2026.09.08 R5

Steam 싱글플레이어 빌드 24723416용 공개 테스트 배포판입니다.
최신 R5의 빌드와 자동 검사는 완료했습니다. 실제 플레이에서 확인한
타이머·성능 개선은 R2의 일부 불러오기 장면이며, R5의 실게임 실행과
조명 변경, 전체 캠페인 검증은 아직 완료하지 않았습니다.

설치
1. 게임 설치·업데이트를 완료하고 게임을 완전히 종료합니다.
2. 기존 dxgi.dll, localize.json, localize_kr.json을 별도 폴더에 백업합니다.
3. 이 ZIP의 파일 세 개를 iw6sp64_ship.exe가 있는 폴더에 복사합니다.
   dxgi.dll
   localize.json
   localize_kr.json
4. Steam에서 싱글플레이어를 실행합니다.

Steam 라이브러리의 게임 관리 메뉴에서 로컬 파일 폴더를 열 수 있습니다.
게임 EXE 교체나 추가 실행 프로그램은 필요하지 않습니다.
두 번역 JSON은 기존 배포본과 동일합니다.

지원 범위
- Steam SP 빌드 24723416의 iw6sp64_ship.exe만 지원합니다.
- 멀티플레이, 구 실행 파일, Microsoft Store/Game Pass판은 지원하지 않습니다.
- 이후 EXE 업데이트의 자동 호환을 보장하지 않습니다.
  지원하지 않는 EXE에서는 한글패치의 게임 훅을 적용하지 않습니다.

조명 설정
게임 실행 중 r_dlightLimit 값을 4로 맞추는 기능이 포함되어 있습니다.
설정 파일을 미리 만들거나 전체 설정 파일을 덮어쓸 필요가 없습니다.
적용은 최초 시도 포함 총 3회, 최소 5초 간격으로 제한합니다.
4로 확인된 뒤 그래픽 옵션으로 값이 바뀌면 다시 적용을 시도합니다.
에이잭스 사망 장면의 실제 조명 개선은 별도 확인이 필요합니다.

문제 제보
미션/장면, 해상도, 새로 시작 또는 불러오기 여부, 증상을 알려주세요.
게임 폴더의 ghostskor_compatibility.txt를 함께 첨부하면 도움이 됩니다.
조명 문제에는 ghostskor_lighting.txt도 함께 첨부해주세요.
조명 로그의 Verified는 설정값 확인을 뜻하며 장면의 시각적 검증은 아닙니다.

삭제·복구
게임을 종료하고 dxgi.dll을 게임 폴더 밖으로 옮기면 비활성화됩니다.
복구에는 현재 EXE에서 작동이 확인된 이전 DLL을 사용하세요.
조명 값은 게임 설정에 저장되어 4로 남을 수 있습니다. 값을 바꾸려면
패치 DLL을 비활성화한 뒤 게임 설정을 변경하세요.

파일 확인
SHA256SUMS.txt에 포함 파일의 SHA-256이 기록되어 있습니다.
DLL은 서명되지 않았으며, 2026-09-08 로컬 Microsoft Defender 검사
(정의 1.459.93.0)에서는 위협이 발견되지 않았습니다.
다른 PC 또는 이후 정의에서의 탐지 결과까지 보장하는 것은 아닙니다.
