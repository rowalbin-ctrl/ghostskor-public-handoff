2026.09.08 R5 변경 내역

- 2026년 8월 Steam SP 실행 파일 업데이트에 대응했습니다.
  지원 EXE와 실행 코드가 확인된 뒤 패치를 초기화합니다.
- 4K 미션 목표, 미션 인트로, 조작 안내, QTE, 타이머의 글자 크기
  계산을 보완했습니다. 실제 장면별 크기와 줄바꿈 확인은 남아 있습니다.
- 타이머가 게임의 현재 시간값을 우선 사용하도록 하여 불필요한
  광범위 시간값 탐색을 줄였습니다. 타이머·문구를 찾는 HUD 탐색은
  유지했습니다. 숫자가 준비되기 전에 원본 타이머를 숨기지 않도록 했습니다.
- 시작 메뉴 글자 폭 함수의 초기화 순서를 동기화했습니다.
- r_dlightLimit 4 적용 기능과 재시도 제한을 추가했습니다.
  명령 큐 호출 중 예외가 나면 그 실행에서는 추가 전송을 중단합니다.
- 함수 31개의 주소를 공통 패턴 검색으로 찾고 검증하도록 했습니다.
  누락·중복·현재 프로필 불일치 시 해당 주소표를 사용하지 않습니다.
  아직 미래의 모든 EXE를 자동 지원하는 기능은 아닙니다.

검증 범위
- R2: 사용자가 일부 불러오기 장면에서 한글·타이머 표시와 성능 개선 확인.
- R5: x64 빌드, 주소 검색/실패 처리, 조명 재시도 정책,
  HUD 크기 계산/타이머 표시 조건 및 기존 코드 검사 통과.
- 미완료: R5 실게임 시작, 조명 값 전환과 에이잭스 장면,
  4K 장면별 크기·줄바꿈, 반복 실행 메뉴 정렬, 전체 캠페인 타이머 확인.
